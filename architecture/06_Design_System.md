# Design System

## Purpose

The design system defines the principles that guide the visual and interactive experience of The Coherence Project.

Its objective is to create an environment where knowledge can be accessed, understood and explored with minimal cognitive effort.

The design system exists to support comprehension.

---

# Design Philosophy

The interface should disappear behind a frictionless experience.

The user should not notice the interface itself.

Instead, the user should naturally focus on the ideas, concepts and knowledge being presented.

A successful interface feels obvious, intuitive and effortless.

---

# Core Principles

## 1. Content Is the Product

The primary product is knowledge.

The interface, visual elements and technology exist to make that knowledge accessible.

Design decisions should always prioritize understanding over appearance.

---

## 2. Reading First

Reading is the primary interaction.

Every page should be designed around comfortable long-form reading.

Typography, spacing and hierarchy are more important than decorative elements.

---

## 3. Zero Cognitive Friction

The experience should minimize unnecessary mental effort.

Users should immediately understand:

- Where they are.
- What they are reading.
- What they can do next.
- How to continue exploring.

The interface should never require users to learn the system before using it.

---

## 4. Intuitive by Default

Common actions should follow established digital patterns.

Navigation should feel predictable.

The user should not need instructions to understand how the experience works.

---

## 5. Simplicity Without Limitation

Simplicity does not mean removing functionality.

It means removing unnecessary complexity.

Advanced capabilities should remain available without creating barriers for new users.

---

## 6. Progressive Disclosure

Information should be revealed according to user needs.

The interface should avoid overwhelming users with unnecessary choices.

Complexity should appear only when it becomes valuable.

---

## 7. Calm Experience

The interface should create an environment suitable for reflection and learning.

Avoid:

- Excessive animations.
- Visual noise.
- Attention-seeking elements.
- Unnecessary interruptions.

---

## 8. Accessibility First

The experience should be usable by the widest possible audience.

Accessibility considerations include:

- Readability.
- Contrast.
- Typography.
- Navigation.
- Responsive behavior.

Accessibility is part of quality, not an additional feature.

---

# Visual Language

The visual identity should communicate:

- Clarity.
- Trust.
- Depth.
- Curiosity.
- Timelessness.

The interface should feel closer to a well-designed contemporary publication than to a traditional corporate website.

---

# Typography

Typography is the primary visual communication tool.

Hierarchy should be created through:

- Size.
- Weight.
- Spacing.
- Structure.

Readable text always has priority over expressive typography.

---

# Color

Color should support organization and navigation.

The palette should be restrained and purposeful.

Colors should never become the main mechanism for communicating meaning.

---

# Layout

Whitespace is an active design element.

The layout should create rhythm and focus.

Content should never feel compressed.

---

# Components

Components should solve communication problems.

A component should exist because it improves:

- Understanding.
- Navigation.
- Discovery.
- Reading experience.

Components should not exist only for visual decoration.

---

# Motion

Motion should communicate changes or relationships.

Animations should be:

- Purposeful.
- Subtle.
- Optional.

Motion should never interrupt reading.

---

# Responsive Experience

The experience should remain coherent across:

- Desktop.
- Tablet.
- Mobile.

The design adapts to the user, not the opposite.

---

## Figures and Editorial Media

Figures should respect the reading experience and remain visually integrated with the surrounding text.

- Maximum width should generally not exceed the content measure.
- Figures should be responsive and scale gracefully on smaller screens.
- Use generous vertical spacing above and below figures to separate them from text.
- Captions should be clearly legible, aligned with the figure, and sized slightly smaller than body text.
- Use formal numbering when appropriate (for example, "Figure 1", "Figure 2" or localized variants like "Figura 1").
- On mobile, figures should adapt to the viewport width and keep captions visible without requiring horizontal scrolling.

The design system treats figures as narrative components that support comprehension across devices.

---

# Design Evolution

The design system should evolve gradually.

Consistency is more valuable than novelty.

Changes should improve understanding and reduce friction.

---

# Final Design Question

Before introducing any visual or interactive element, ask:

"Does this help the user understand, navigate or explore knowledge more easily?"

If not, it should not exist.
