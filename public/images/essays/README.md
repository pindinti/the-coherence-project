# Essays Images

This folder contains images for essay content.

Each essay may have its own subfolder named exactly after the essay slug. This keeps editorial assets tied to the content item while preserving a clear public asset structure.

Example:
- `public/images/essays/organizational-coherence/`
- `public/images/essays/coerencia-organizacional/`

Prefer SVG for diagrams and use descriptive kebab-case file names.
