# Public Editorial Images

This directory contains editorial images, illustrations, diagrams and figures used by The Coherence Project.

Assets are organized by content type and by content slug to keep editorial media separated from architecture, source content and application code.

- `essays/` — assets for essays
- `articles/` — assets for articles
- `journal/` — assets for journal entries
- `research/` — assets for research notes
- `pages/` — assets for static pages
- `shared/` — assets used across multiple items

Use descriptive kebab-case file names and prefer SVG for diagrams. When the same image is identical across languages, store it under `shared/` rather than duplicating it.
