# The Coherence Project

*A long-term research project on Organizational Coherence.*

---

## Overview

The Coherence Project is an independent research initiative dedicated to developing, testing and communicating the theory of **Organizational Coherence**.

Rather than focusing on isolated management tools or business trends, the project investigates a fundamental question:

> **How can organizations consistently deliver the promises they make?**

The project combines theoretical research, practical experimentation and educational content into a single evolving body of knowledge.

---

## Repository Structure

The repository is organized around four major areas:

- architecture/ — Project architecture and governance
- content/ — Multilingual Markdown content and supporting research
- src/ — Website source code
- public/ — Static assets

---

# Project Philosophy

The Coherence Project follows a simple principle:

> **Knowledge is the product.**

Everything else exists to make that knowledge easier to understand, explore and apply.

Technology serves content.

Design serves comprehension.

Research drives evolution.

# Content Types

The canonical knowledge domains are Essays, Articles, The Coherence Journal, Research and Podcast. Their definitions and relationships are maintained in `architecture/02_Information_Architecture.md`; the purpose-based publishing model is maintained in `architecture/03_Content_Strategy.md`.

# Languages

# Technical Philosophy

The project follows a content-first architecture.

```text
Markdown

↓

Static Site Generator

↓

GitHub Pages

↓

Website
```

Markdown is the canonical source of knowledge.

The website is only one possible representation of that content.

# Guiding Principles

The project values:

- Clarity over complexity.
- Understanding over persuasion.
- Consistency over novelty.
- Evolution over reinvention.
- Evidence over opinion.
- Long-term thinking over short-term optimization.

---

# Long-Term Vision

The Coherence Project is intended to become a living knowledge platform.

Additional future formats may include:

- Courses
- Talks
- Workshops
- Research collaborations

Regardless of format, the central objective remains unchanged:

> **Help people better understand how organizations become coherent.**
