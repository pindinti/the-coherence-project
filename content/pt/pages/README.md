# Páginas em Português (Portuguese Pages)

Este diretório contém páginas estáticas do site em português (ex: Sobre).

## Diretrizes de Conteúdo

- Todos os arquivos devem seguir o schema canônico de Frontmatter definido em `architecture/10_Content_Model.md`.

## Modelo de Frontmatter

```yaml
---
title: "Sobre O Projeto Coerência"
description: "Informações sobre o projeto, missão e autor."
author: "Nome do Autor"
date: 2026-08-03
language: "pt"
type: "page"
tags: ["sobre", "meta"]
status: "published"
translationId: "page-about"
---
```
