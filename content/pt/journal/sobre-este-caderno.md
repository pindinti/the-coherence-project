Este caderno registra um programa de pesquisa.

Toda organização nasce de milhares de decisões. Algumas são grandes. A maioria é pequena: um nome, uma embalagem, um processo, uma conversa, uma contratação. Costumamos enxergar essas decisões como eventos isolados. A hipótese que orienta este trabalho é que elas não são independentes. Quando uma organização possui uma promessa clara, cada decisão passa a influenciar as próximas, formando um padrão de desenvolvimento.

Este caderno existe para observar esse processo.

Cada registro documenta um ciclo de investigação. Primeiro, uma decisão. Depois, as consequências que ela produz na organização. Por fim, as hipóteses que essas consequências levantam sobre o próprio modelo que orientou a decisão.

A ordem é deliberada.

Não parto da teoria para demonstrá-la, nem da prática para ilustrá-la. A teoria orienta as decisões. A prática revela suas consequências. Essas consequências, por sua vez, podem confirmar, ampliar ou contradizer a própria teoria.

Por isso, as hipóteses registradas aqui não são conclusões. São hipóteses de trabalho. Algumas serão fortalecidas por novos registros. Outras serão abandonadas. O objetivo deste caderno não é defender um modelo, mas submetê-lo continuamente à realidade.

Os ensaios apresentam, em cada momento, a melhor formulação teórica que consegui construir. Este caderno registra o processo pelo qual essa formulação é continuamente colocada à prova.

Se este experimento funcionar, tanto as organizações observadas quanto a própria teoria terminarão diferentes de como começaram.
