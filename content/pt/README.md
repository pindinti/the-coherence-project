# Portuguese Content

This directory contains the Portuguese source content for The Coherence Project.

## Directory Structure

```text
content/pt/
├── essays/     # Fundamentação teórica e ensaios originais
├── articles/   # Artigos educacionais e explicativos
├── journal/    # Diário de bordo e experimentos práticos
├── research/   # Notas de pesquisa e referências
└── pages/      # Páginas estáticas do site (ex: Sobre)
```

All Markdown files must adhere to the canonical Frontmatter schema defined in `architecture/10_Content_Model.md`.
