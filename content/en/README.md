# English Content

This directory contains the English source content for The Coherence Project.

## Directory Structure

```text
content/en/
├── essays/     # Theoretical foundations and long-form research
├── articles/   # Educational and accessible publications
├── journal/    # Empirical observations and experiments
├── research/   # Notes, references and working ideas
└── pages/      # Static site pages (e.g. About)
```

All Markdown files must adhere to the canonical Frontmatter schema defined in `architecture/10_Content_Model.md`.
